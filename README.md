# MediMinder – Reminder App

## Project Overview

**MediMinder** is an Android-based medicine reminder application developed as a project for **Bachelor of Science Honours (Computer Science)**.

The application is designed to help users manage their medication schedules, receive medicine reminders, maintain prescription and medical information, track water intake, and access important health-related features.

The project was developed during the academic year **2024–2025**.

## Problem Statement

In today's busy lifestyle, people may forget to take their medicines at the prescribed time. This can result in missed doses, irregular medication intake, and difficulties in managing multiple medications.

MediMinder aims to provide a simple application that helps users:

* Remember their medication schedules.
* Store dosage and prescription information.
* Track medicine quantities and refills.
* Maintain basic medical history.
* Set water intake reminders.
* Store emergency contacts.
* Access health tips and information.

## Core Features

### 💊 Medication Reminder

Users can add medicines and set reminders according to their prescribed schedule.

### ⏰ Medicine Alarm

Users can set the required time for taking a particular medicine and add instructions provided by their doctor.

### 💧 Water Intake Reminder

The application allows users to set intervals for drinking water and maintain healthy hydration habits.

### 📋 Dosage and Prescription Details

Users can store medication dosage, frequency, instructions, and prescription-related information.

### 🔄 Pill Count and Refill Tracking

Users can monitor their medicine stock and keep track of when medicines need to be refilled.

### 📅 Appointment Management

Users can create and manage appointments with doctors.

### 👤 User Profile

The profile section allows users to enter information such as:

* Full Name
* Weight
* Height
* Allergies
* Existing Medical Conditions

### 🚨 Emergency Contacts

Users can store emergency contacts, including:

* First Name
* Last Name
* Relationship
* Contact Number

### 🏥 Health Tips

The application provides daily health tips and useful information related to health and wellness.

### 📄 Prescription Storage

Users can upload and store prescription images from their device.

### ⭐ Feedback

Users can provide feedback and ratings about their experience with the application.

### 📝 Medical History

The application provides a place to maintain previous medical and medication-related information.

## Technologies Used

### Android Studio

Android Studio was used as the main Integrated Development Environment (IDE) for developing the Android application.

### Firebase

Firebase is used for backend-related functionality, including:

* Firebase Authentication
* Firebase Storage
* Firebase Realtime Database
* Firebase Notifications

### JSON

JSON (JavaScript Object Notation) is used as a lightweight format for representing and transmitting structured data.

## Benefits

MediMinder provides several benefits:

* Helps improve medication adherence.
* Reduces the chances of forgetting medication.
* Helps users organize multiple medicines.
* Provides easy access to prescription information.
* Supports emergency contact management.
* Encourages regular water intake.
* Provides health-related information.
* Helps users maintain basic medical information.

## Limitations

The application has some limitations:

* Its effectiveness depends on correct user input.
* Reminders depend on device availability and notification settings.
* Too many notifications may cause notification fatigue.
* The application cannot force users to take their medication.
* The current application is designed for the Android platform.
